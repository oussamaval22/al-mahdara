# تعديل صفحة المصحف

- حجم صورة المصحف ثابت دائمًا.
- الضغط على الصورة يُظهر أو يخفي أزرار حفظ الصفحة والفهرس والاستماع فقط.
- الأزرار تظهر كطبقة فوق الصورة ولا تغير أبعاد `FlatList` أو الصورة.
- على Android يتم إخفاء شريط التنقل مؤقتًا عند دخول صفحة المصحف باستخدام `expo-navigation-bar`.
- يمكن إظهار شريط التنقل مؤقتًا بالسحب من أسفل الشاشة إلى أعلى.
- عند الخروج من صفحة المصحف يعود شريط التنقل للظهور.

## التشغيل

```bash
npm install
npx expo install expo-navigation-bar
npx expo start -c
```

ثم امسح QR عبر Expo Go إذا كان إصدار Expo Go متوافقًا مع SDK المشروع.
