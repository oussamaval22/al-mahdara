# المحظرة — Local Quran Pages

تم تعديل قارئ القرآن ليعتمد على صور المصحف المحلية فقط من:

`assets/quran_image/1.png` إلى `assets/quran_image/604.png`

لا يتم استخدام API لعرض صفحات المصحف.

## إضافة الصور
ضع صور المصحف داخل:

```text
assets/quran_image/
  1.png
  2.png
  ...
  604.png
```

ثم شغّل:

```bash
npm run generate:quran-images
npm run typecheck
npx expo start -c
```

> الصور لم تكن موجودة داخل الملف المضغوط الذي تم فحصه؛ لذلك لا يمكن تضمينها في النسخة الحالية دون رفعها. مولد الصور سيضيف فقط الملفات الموجودة فعلًا.

## قارئ المصحف
- الصور المحلية فقط.
- السحب يمين/يسار بين الصفحات.
- الضغط على الصفحة يظهر/يخفي شريط التحكم.
- حفظ الصفحة.
- الانتقال إلى الفهرس.
- الانتقال إلى الاستماع.
